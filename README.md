# AfriShop

Site vitrine d'une boutique de produits africains, réalisé dans le cadre d'un TP d'initiation à Git et GitHub.

## Description

AfriShop présente ses produits (mode africaine, artisanat, produits locaux) à travers une page unique : accueil, catalogue de trois produits avec leurs prix, et section contact.

## Auteur

Enongnong Alexandre William Scott

## Technologies utilisées

- HTML5
- CSS3 (Flexbox)
- Git et GitHub pour le versionnage
- Visual Studio Code

## Lancer le projet

1. Cloner le dépôt :

```
git clone https://github.com/landerscott237-pixel/AfriShop.git
```

2. Ouvrir le dossier `AfriShop`.
3. Double-cliquer sur `index.html` pour l'ouvrir dans un navigateur.

Aucune installation supplémentaire n'est nécessaire.
